# Tokenotch for Windows 1.0.0

Regular public Windows release, with native x64 and ARM64 installers.
The app uses the `release` channel. **These installers are unsigned**:
they are not Authenticode-signed or Microsoft-certified. Windows reputation
warnings and managed-device policies may block installation. Do not disable
those protections.

## Requirements and installation

The Windows target is **Windows 11 24H2 (build 26100) or later**, with the
installer matching your PC's native architecture. WebView2 is required; setup
may download its runtime. GitHub Copilot CLI and/or VS Code must run locally
on the same PC.

Compare the downloaded installer's SHA-256 with the checksum below or its
`.exe.sha256` file, using `Get-FileHash -Algorithm SHA256` in PowerShell.
Close Tokenotch before installing or reinstalling. Setup is per-user and
retains existing usage history. Open **Connections** after launch to connect
your clients; usage history is on by default and can be paused in Privacy.

See the [Windows setup guide](https://github.com/rottathiago/tokenotch/blob/main/windows/README.md)
for connection steps, client limitations and removal instructions.

## Included

- Side-notch widget, usage/session summary, tray controls and multi-display placement.
- Local Copilot CLI and VS Code connections with consent-based setup.
- Token/model breakdowns, live context/activity and optional official account quota.
- Usage history, session timelines, imports and configurable Windows notifications.
- Bundled Windows helper, VS Code companion and MIT license notices.

## Build provenance and limits

The installers are unchanged artifacts from
[Windows build checks run 37853848609](https://github.com/rottathiago/tokenotch/actions/runs/37853848609)
for source revision
[`c9283b7d0815d0f48b0e21cc2af503cff8b86831`](https://github.com/rottathiago/tokenotch/commit/c9283b7d0815d0f48b0e21cc2af503cff8b86831),
tagged `v1.0.0-windows`. Product version is 1.0.0, build 1.

Both native architecture jobs passed packaging, browser checks and disposable
install/helper/uninstall checks. Required native and documentation CI also
passed for that source revision. The x64 hosted runner is Windows Server;
these results are not full Windows 11 desktop, real-client, accessibility,
upgrade/recovery or macOS feature-parity certification. Remote clients and
automatic update installation are not supported.

This Windows-specific release does not replace the macOS `v1.0.0` release or
its "latest release" download URLs.
