# Tokenotch 1.0.0

Release candidate notes. Publish only after the signed artifact and acceptance
record are approved.

- Visibility into token consumption, model usage and usage patterns across
  GitHub Copilot CLI and Visual Studio Code sessions, with attention alerts when
  a session needs your action.
- VS Code Local lifecycle hooks and separately enabled Local/Agent Host usage;
  Agent Host lifecycle and attention parity are not claimed.
- Universal Apple Silicon/Intel application and native helper, targeting macOS 15+.
- Updated Tokenotch logo throughout the app, menu bar, onboarding, and bundled companion.
- Resumable first-run setup and separate, explicit privacy choices.
- Explicit runtime compatibility, stale/unavailable data, and cleanup feedback.
- Manual update lookup linking to the official stable release.
- Independently opt-in notifications, history, session timelines, and remembered notices.

Preview capabilities depend on client versions. Local observations can be
incomplete and are not account-wide billing or proof of task success. Remote
clients, other IDEs/providers, and Windows are not supported by this release.

Tokenotch is an independent project and is not affiliated with or endorsed by
GitHub or Microsoft.
