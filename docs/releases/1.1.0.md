# Tokenotch 1.1.0

macOS release, build 2, for Apple Silicon and Intel on macOS 15 or later.
Windows installers remain on their separate release.

- Claude Code CLI usage, optional local Claude Desktop Code-tab metrics, and
  separately enabled CLI session and status-line reporting.
- Separate Copilot and Claude notch cells, provider/client filters, estimated
  Claude cost coverage, and independently consented recording and deletion.
- Transactional history and session migrations that preserve existing Copilot
  observations and keep new provider collection off until approved.
- Optional daily update checks while Tokenotch is open, a menu-bar update
  indicator, and once-per-release banners when notifications are enabled.
  Update alerts respect managed mute, categories, snooze and quiet hours.
  Downloading and installation remain manual.
- Updated setup, connection readiness, telemetry handling, regression checks
  and privacy documentation.

## Updating from 1.0.0

Choose **Check for Updates** in Tokenotch, then **Open Official Release**.
Quit Tokenotch, install the new app in Applications, and reopen it. Preferences
and saved observations are retained. Review Connections for any client reload
or repair instructions.

Version 1.0.0 has no background checks or push-notification receiver; it cannot
automatically announce this release. After upgrading, enable **Settings > About >
Check for updates daily** to discover future releases automatically. For banners,
also enable notifications in Tokenotch and allow them in macOS.

## Important limitations

These installers are unsigned and not notarized. macOS may require the normal
**System Settings > Privacy & Security > Open Anyway** approval where allowed.
Never disable Gatekeeper or remove quarantine.

Back up saved data before upgrading: history migrates to schema 7 and session
timelines to schema 4. Older binaries cannot read the upgraded archives, and
there is no reverse migration. Do not delete saved data to force a downgrade.

Claude features are optional and have client-specific limitations. Synthetic
checks do not establish full real-client, Desktop, VoiceOver, physical
multi-display, or lifecycle acceptance. See the
[Claude integration contract](https://github.com/rottathiago/tokenotch/blob/v1.1.0/docs/claude-code-contract.md) for verified evidence
and unsupported observations. Local usage and estimated cost are not billing
records or proof of task success.
